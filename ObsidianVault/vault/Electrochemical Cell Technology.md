# Electrochemical Cell Technology


## Summary
Electrochemical cell technology detects nitrogen dioxide (NO2) gas by generating an electric current through chemical reactions when NO2 contacts internal sensor chemicals. The magnitude of the generated current is directly proportional to the gas concentration.

## Key Data / Findings

| Component / Attribute | Details |
|---|---|
| Target Gas | Nitrogen Dioxide (NO2) |
| Operating Mechanism | Chemical reaction generates current proportional to gas concentration |
| Internal Hardware Elements | Gas diffusion barrier, Working Electrode, Reference Electrode, Counter Electrode, Electrolyte Reservoir, Wetting filters |
