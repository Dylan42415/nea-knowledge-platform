# Air Dispersion Model


## Summary
The customized air dispersion model integrates data from low-cost sensors, real-time meteorological conditions, traffic emissions, and background station concentrations to generate continuous hourly air quality heat maps. It met US EPA target values during validation tests using portable PM2.5 analysers.

## Key Data / Findings

| Validation Parameter | Measured Range | US EPA Benchmark Target |
|---|---|---|
| Model R² | 0.70 to 0.97 | ≥ 0.7 |
| Model RMSE | 1.80 to 3.70 µg/m³ | ≤ 7 µg/m³ |
| Validation Setup | Portable PM2.5 analyser at 4 sites | ~1 week per location |
