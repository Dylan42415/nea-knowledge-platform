# Low-Cost Air Quality Sensors


## Summary
Low-cost air quality sensors are compact, portable monitoring units that enable localized air quality measurements at high spatial and temporal resolution. NEA tested a network of 28 low-cost sensors across a residential estate to evaluate vertical dispersion, road traffic impact, and dispersion modeling.

## Key Data / Findings

| Metric / Parameter | Value / Detail |
|---|---|
| Footprint Comparison | 1 ambient air monitoring station = > 3000 low-cost sensors |
| Trial Data Completeness | Close to 100% |
| Residential Estate Sensor Network Size | 28 low-cost sensors |
| Initial Calibration Procedure | Co-located with NEA air quality monitoring station |
| PM2.5 Accuracy (R² / RMSE) | R² = 0.73, RMSE = 3.14 µg/m³ |
| NO2 Accuracy (R² / RMSE) | R² = 0.42, RMSE = 11.0 µg/m³ |
