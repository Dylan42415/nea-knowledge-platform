# Meteorological Service Singapore (MSS)


## Summary
MSS operates haze forecasting systems based on dispersion models and collaborates on regional atmospheric monitoring.

## Key Data / Findings

| Function | System / Tool |
|---|---|
| Haze Forecasting | Operationalised haze forecasting system based on the NAME model |
| Regional Centre | Contributes to WMO VFSP-WAS SEA regional centre multi-model ensemble |
