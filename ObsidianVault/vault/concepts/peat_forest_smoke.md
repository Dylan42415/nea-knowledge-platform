# Peat-forest smoke


## Summary
Transboundary smoke originating from underground burning of peat forests, characterized by organic carbon and elemental carbon components.

## Key Data / Findings

| Feature | Significance |
| :--- | :--- |
| Char-EC > Soot-EC | Smoldering-prominent burning (e.g., peatland) |
| Soot-EC > Char-EC | Flaming-prominent burning (e.g., on-ground forest fires) |
