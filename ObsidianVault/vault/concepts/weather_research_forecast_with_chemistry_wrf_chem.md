# Weather Research Forecast with Chemistry (WRF-Chem)


## Summary
WRF-Chem is a customized regional numerical weather prediction and atmospheric chemistry model optimized for Singapore conditions by CRISP. It simulates the formation and transport of transboundary biomass-burning smoke.

## Key Data / Findings

| Configuration Parameter | Value | Reference / Source |
|---|---|---|
| Customized Model Version | V3.6 | Applied for September 2019 smoke event simulation |
| Simulation Grid Resolution | 9 x 9 km2 | Customized over Southeast Asia region |
| Meteorological Input | GFS (Global Forecasting System) | External weather boundary conditions |
| Emissions Inventory Input | FLAMBE | Fire Locating and Modeling of Burning Emissions |
| Model Run Date | 12 September 2019, 03 UTC | Evaluated against Terra MODIS satellite images |
