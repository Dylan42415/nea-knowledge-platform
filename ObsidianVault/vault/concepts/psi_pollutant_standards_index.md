# PSI (Pollutant Standards Index)


## Summary
An index used to report air quality, computed based on six criteria air pollutants. In 2014, PM2.5 was added to the five existing pollutants used for the 24-hour PSI calculation.

## Key Data / Findings

| Pollutant Addition Date | Impact |
| :--- | :--- |
| 2014 (PM2.5 included) | Resulted in a lower percentage of days in the 'good' range |
