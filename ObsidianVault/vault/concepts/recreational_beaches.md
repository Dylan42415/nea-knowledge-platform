# Recreational Beaches


## Summary
Seven monitored recreational beaches achieved a 'Good' performance banding in 2020, meeting primary contact recreational water quality standards.

## Key Data / Findings

| Beach Name | 2020 Performance Banding | Guideline Standard |
|---|---|---|
| Changi beach | Good | ≤ 200 counts/100ml (95th percentile) |
| East Coast Park beach | Good | ≤ 200 counts/100ml (95th percentile) |
| Pasir Ris beach | Good | ≤ 200 counts/100ml (95th percentile) |
| Punggol beach | Good | ≤ 200 counts/100ml (95th percentile) |
| Seletar Island beach | Good | ≤ 200 counts/100ml (95th percentile) |
| Sentosa Island beach | Good | ≤ 200 counts/100ml (95th percentile) |
| Sembawang Park beach | Good | ≤ 200 counts/100ml (95th percentile) |
