# ESBL resistant Escherichia coli


## Summary
Extended-spectrum β-lactamases (ESBL) resistant bacteria, which are resistant to last resort antibiotics, monitored in Singapore's marine waters.

## Key Data / Findings

| Site | Average Concentration |
| :--- | :--- |
| Singapore coastal/aquaculture | 10 CFU/100mL |
| Netherlands recreational (2010) | 1 CFU/100mL |
