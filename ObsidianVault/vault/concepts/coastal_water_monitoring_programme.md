# Coastal Water Monitoring Programme


## Summary
A water quality monitoring network covering the Straits of Singapore and the Straits of Johor using 43 sampling points and 8 buoy-based monitoring stations.

## Key Data / Findings

| Component | Value |
| :--- | :--- |
| Manual sampling points | 43 |
| Buoy-based stations | 8 |
| Commissioning date | 2014 |
