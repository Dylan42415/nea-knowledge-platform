# Geostationary Environmental Monitoring Spectrometer (GEMS)


## Summary
GEMS is an atmospheric chemistry satellite mission launched in 2019 by the Republic of Korea on the GEO-KOMPSAT 2B satellite. It provides high temporal and spatial resolution measurements of AOD and trace gases over Asia.

## Key Data / Findings

| Parameter | Specification |
|---|---|
| Launch Year | 2019 |
| Satellite Host | GEO-KOMPSAT 2B |
| Spectral Range | UV-Visible |
| Atmospheric Products | AOD, O3, NO2, SO2 column amounts |
