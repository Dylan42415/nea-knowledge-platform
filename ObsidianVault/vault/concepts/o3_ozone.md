# O3 (Ozone)


## Summary
Atmospheric ozone created via complex reactions between nitrogen oxides (NOX) and volatile organic compounds (VOCs) in the presence of sunlight. Its production is a non-linear function of precursor emissions.

## Key Data / Findings

| Parameter | Characteristic |
| :--- | :--- |
| Formation | Non-linear function of NOX and VOCs |
