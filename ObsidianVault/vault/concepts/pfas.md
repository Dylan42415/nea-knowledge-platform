# PFAS


## Summary
Per- and polyfluoroalkyl substances used in various consumer products, characterized by bioaccumulative and carcinogenic properties.

## Key Data / Findings

| Parameter | Concentration |
| :--- | :--- |
| Singapore Total PFASs | <14.2-80ng/L |
| PFOS (Singapore) | <24ng/L |
| PFOA (Singapore) | <21ng/L |
| USEPA Health Advisory (PFOS+PFOA) | 70ng/L |
