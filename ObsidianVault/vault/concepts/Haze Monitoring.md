# Haze Monitoring


## Summary
Haze monitoring in Singapore integrates ground instruments (such as PM2.5 sensors, AERONET sun-photometers, and MPLNET LIDAR) with satellite remote sensing (MODIS, Himawari 8/9, GEMS) and numerical models (WRF-Chem, NAME).

## Key Data / Findings

| Component | Technologies / Networks | Key Organizations |
|---|---|---|
| Ground Instruments | PM2.5 sensors, AERONET Sun-photometers, MPLNET Lidar | NEA, NUS/CRISP, MSS |
| Satellites | MODIS (Terra/Aqua), Himawari 8/9, GEMS (GEO-KOMPSAT 2B) | NASA, JAXA, Republic of Korea |
| Numerical Models | WRF-Chem, NAME | WMO VFSP-WAS SEA regional centre |
