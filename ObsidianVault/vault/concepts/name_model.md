# NAME Model


## Summary
The Numerical Atmospheric-dispersion Modelling Environment (NAME) is a Lagrangian dispersion model utilized by the Meteorological Service Singapore (MSS) to run an operational haze forecasting and source-attribution system for regional PM10 and PM2.5.

## Key Data / Findings

| System Component | Detail | Website / Reference |
|---|---|---|
| Primary Operator | Meteorological Service Singapore (MSS) | Source attribution of biomass burning PM10 |
| Forecast Output Portal | https://www.mss-int.sg/vfsp-was/forecasts/smoke-forecasts | Features multi-model ensemble predictions |
