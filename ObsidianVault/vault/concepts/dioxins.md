# Dioxins


## Summary
Persistent organic pollutants (POPs) comprising PCDDs and PCDFs, often released through waste incineration. Toxicity is measured using TEQ values.

## Key Data / Findings

| Metric | Value |
| :--- | :--- |
| 2020 Concentration | 0.8 fg-TEQ/m³ |
| Japan Standard Benchmark | 600 fg-TEQ/m³ |
