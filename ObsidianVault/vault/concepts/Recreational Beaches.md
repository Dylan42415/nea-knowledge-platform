# Recreational Beaches


## Summary
Water quality across seven monitored recreational beaches in Singapore is evaluated using enterococcus counts. All seven monitored beaches achieved a 'Good' banding in 2020, making them suitable for primary contact recreational activities.

## Key Data / Findings

| Beach Name | Monitored Parameter | 2020 Banding | Guideline Threshold |
|---|---|---|---|
| Changi beach | Enterococcus | Good | ≤ 200 counts/100ml (95th percentile) |
| East Coast Park beach | Enterococcus | Good | ≤ 200 counts/100ml (95th percentile) |
| Pasir Ris beach | Enterococcus | Good | ≤ 200 counts/100ml (95th percentile) |
| Punggol beach | Enterococcus | Good | ≤ 200 counts/100ml (95th percentile) |
| Seletar Island beach | Enterococcus | Good | ≤ 200 counts/100ml (95th percentile) |
| Sentosa Island beach | Enterococcus | Good | ≤ 200 counts/100ml (95th percentile) |
| Sembawang Park beach | Enterococcus | Good | ≤ 200 counts/100ml (95th percentile) |
