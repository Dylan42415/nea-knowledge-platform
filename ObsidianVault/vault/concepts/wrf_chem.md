# WRF-Chem


## Summary
WRF-Chem (Weather Research Forecast with Chemistry) is a numerical prediction model customized by CRISP for Singapore conditions. It simulates transboundary pollutant transport, land-cover impacts, and biomass burning smoke dispersion across Southeast Asia.

## Key Data / Findings

| Model Parameter | Configuration / Data Source |
|---|---|
| Model Version | Customized WRF-Chem V3.6 |
| Horizontal Grid Resolution | 9 x 9 km² |
| Meteorological Input | Global Forecasting System (GFS) |
| Emissions Inventory | FLAMBE (Naval Research Laboratory) |
