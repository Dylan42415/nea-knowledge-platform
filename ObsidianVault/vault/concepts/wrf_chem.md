# WRF-Chem


## Summary
WRF-Chem (Weather Research Forecast with Chemistry) is a numerical weather prediction model customized by CRISP over a 9 x 9 km² grid for Singapore conditions. It incorporates meteorological input from GFS and emissions inventories from FLAMBE to simulate transboundary smoke dispersion.

## Key Data / Findings

| Configuration Parameter | Specification |
|---|---|
| Model Version | WRF-Chem V3.6 |
| Horizontal Grid Resolution | 9 x 9 km² |
| Meteorological Input Data | Global Forecasting System (GFS) |
| Emissions Inventory Data | FLAMBE (Naval Research Laboratory) |
