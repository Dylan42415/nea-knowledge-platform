# Peat Forest Smoke Indicator


## Summary
An analytical index developed by NERI using unique organic carbon ratios in carbonaceous PM2.5 profiles to identify regional peatland forest burning origins.

## Key Data / Findings

| Application Event | Outcome |
|---|---|
| 2019 Haze Episode | Verified that PM2.5 primarily originated from regional peatland burning |
