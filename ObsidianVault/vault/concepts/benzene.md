# Benzene


## Summary
A VOC occurring in crude petroleum, monitored by the NEA for carcinogenicity. Ambient levels have been decreasing since 2015 due to industrial and transportation emission controls.

## Key Data / Findings

| Metric | Value |
| :--- | :--- |
| 2020 Avg Ambient Concentration | 0.28 ppb |
| 5-Year Range (2015-2020) | 0.3 – 0.5 ppb |
| Industry Emission Limit | 5 mg/Nm³ |
| Petrol Content Limit | 1% by volume |
