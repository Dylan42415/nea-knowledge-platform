# 2019 Haze Episode


## Summary
The 2019 Haze Episode was a significant air pollution incident in Singapore. Chemical analysis using NERI's peat forest smoke indicator verified that elevated PM2.5 concentrations during this event stemmed primarily from regional peat-land burning.

| Attribute | Details |

| Key Source Identified | Regional peat-land burning (higher fractions of organic carbon unique ratios) |
