# Low-Cost Air Quality Sensors


## Summary
Low-cost air quality sensors are portable, lightweight monitoring units deployed in spatial networks to evaluate local ambient and vertical pollutant gradients.

## Key Data / Findings

| Metric / Physical Parameter | Value |
|---|---|
| Size Comparison | 1 typical air quality monitoring station is equivalent in size to >3000 low-cost sensors |
| Trial Grid Scale | 28 co-located and deployed sensors in a residential estate |
| Key Monitored Parameters | PM2.5, Nitrogen Dioxide (NO2) |
