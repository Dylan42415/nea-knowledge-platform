# Transboundary Peat-Forest Smoke


## Summary
Transboundary smoke episodes originating from underground peatland fires in Southeast Asia significantly impact Singapore's urban atmospheric environment, particularly during El Nino years.

## Key Data / Findings

| Event / Parameter | Value | Description |
|---|---|---|
| 2015 Smoke Episode Duration | ~3 months | Longest smoke episode in Singapore, coinciding with an El Nino year |
| Significant Episodes | 2013 and 2015 | Major smoke haze episodes with distinct meteorological drivers |
| Peatland Occupation by 2015 | >60% | Expanded use of original pristine peat-swamp forests (Miettinen et al. 2016) |
