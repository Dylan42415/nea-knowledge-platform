# Inland Water Monitoring Programme


## Summary
A monitoring program comprising 74 sampling locations in water catchment and non-catchment areas, with sampling frequencies ranging from fortnightly to quarterly.

## Key Data / Findings

| Metric | Value |
| :--- | :--- |
| Sampling locations | 74 |
| Sampling frequency | Fortnightly to quarterly |
