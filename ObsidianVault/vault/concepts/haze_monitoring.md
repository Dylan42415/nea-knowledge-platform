# Haze Monitoring


## Summary
Haze monitoring in Singapore utilizes a combination of ground instrumentation (PM2.5 networks, AERONET Sun-photometers, MPLNET lidars), environmental remote sensing satellites (MODIS, Himawari-8/9, GEMS), and numerical models (WRF-Chem, NAME).

## Key Data / Findings

| Technology / Tool | Instrument / Model | Function / Resolution |
|---|---|---|
| Ground Network | PM2.5 instruments | Direct/indirect island-wide measurements |
| Ground Profiling | AERONET Sun-photometer | Aerosol optical depth (AOD) measurements |
| Atmospheric Profiling | MPLNET micro-pulse LIDAR | Near real-time vertical scanning, aerosol/haze layer altitude |
| Satellite Imaging | MODIS (Terra & Aqua) | Forest fire activity and smoke dispersion |
| High-Frequency Satellite | JAXA Himawari 8/9 | Imaging entire Asian hemisphere every 10 min (2 km resolution) |
| Atmospheric Chemistry | GEMS (GEO-KOMPSAT 2B) | UV-visible AOD, O3, NO2, SO2 column amounts |
| Numerical Prediction | WRF-Chem (V3.6) | 9 x 9 km² grid simulation of biomass-burning smoke |
