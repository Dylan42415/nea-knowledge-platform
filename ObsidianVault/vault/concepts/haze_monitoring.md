# Haze Monitoring


## Summary
Haze Monitoring in Singapore integrates ground-based PM2.5 samplers, vertical atmospheric profiling LIDARs/sun-photometers, high-frequency satellite remote sensing, and numerical modeling. This system tracks long-range biomass burning smoke transported during the Southwest Monsoon.

## Key Data / Findings

| Event / Parameter | Value / Metric | Description |
|---|---|---|
| Southwest Monsoon Haze Season | June to early October | Annual dry season in SEA |
| Intense Historic Haze Years | 1997, 2006, 2010, 2013, 2015, 2019 | Exacerbated by El Niño phenomena |
| 2019 Haze Episode Peak PM2.5 | 159 µg/m³ | 14 September 2019 at 3:00 PM |
| Himawari8/9 Satellite Frequency | Every 10 min | Spatial resolution of 2 km |
