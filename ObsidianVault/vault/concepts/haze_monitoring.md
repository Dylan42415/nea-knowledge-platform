# Haze Monitoring


## Summary
Haze monitoring combines ground-based PM2.5 instrument networks, vertical profiling tools like AOD Sun-photometers and LIDAR, and environmental satellites to track transboundary smoke episodes.

## Key Data / Findings

| Instrument / System | Function / Coverage |
|---|---|
| NEA PM2.5 Ground Network | Direct/indirect measurements island-wide |
| AERONET Sun-photometer | Total concentration / Aerosol Optical Depth (AOD) |
| MPLNET Micro-pulse LIDAR | Near real-time vertical scanning / cloud and aerosol altitude |
| MODIS (Terra & Aqua) | Forest fire activity and smoke/haze dispersion over vast areas |
| Himawari 8/9 | High frequency imaging every 10 min across Asian hemisphere |
| GEMS (GEO-KOMPSAT 2B) | Atmospheric chemistry and trace gas column amounts |
