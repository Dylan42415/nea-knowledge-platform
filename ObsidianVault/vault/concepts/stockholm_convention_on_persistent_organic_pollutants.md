# Stockholm Convention on Persistent Organic Pollutants


## Summary
The Stockholm Convention on Persistent Organic Pollutants is an international environmental treaty aimed at eliminating or restricting persistent organic pollutants (POPs) such as dioxins. Singapore has been a signatory state to the convention since 2001.

## Key Data / Findings

| Attribute | Value |
|---|---|
| Scope | Persistent Organic Pollutants (POPs) control |
| Target Chemical Family | Dioxins (PCDDs and PCDFs) |
| Singapore Accession Year | Signatory since 2001 |
| Regulatory Impact | Emission limits on industrial incineration plants |
