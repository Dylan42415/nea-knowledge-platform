# Peat Forest Smoke Indicator


## Summary
The peat forest smoke indicator is a specialized analytical tool developed by NERI. It analyzes unique organic carbon ratios within the carbonaceous profile of PM2.5 to verify whether haze pollution originates from regional peat-land burning.

## Key Data / Findings

| Metric / Application | Detail |
|---|---|
| Developer | NUS Environmental Research Institute (NERI) |
| Key Event Applied | 2019 Haze Episode |
| Key Finding | Established that PM2.5 mainly originated from regional peat-land burning |
| Diagnostic Biomarker | Unique ratios of organic carbon in PM2.5 carbonaceous profile |
